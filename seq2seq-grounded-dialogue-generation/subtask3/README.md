# Subtask 3 — Document-Grounded Dialogue Generation in Hinglish

Build a multi-turn Hinglish dialogue generator conditioned on both conversation history and a grounding document.

Use the CMU Hinglish DoG dataset from the assignment source. Compare an ungrounded generator with the full grounded model and evaluate with BLEU/ROUGE plus qualitative grounding, relevance, fluency and hallucination checks.
