# Recommender Systems: From Neighbors to DLRM

Three-step progression:
1. Memory-based and model-based collaborative filtering.
2. Neural CTR prediction on 13 numerical + 26 categorical features.
3. DLRM-style CTR prediction with embeddings and explicit pairwise interactions.

Tasks 2 and 3 use the same supplied advertising dataset for fair comparison. Task 1 uses an independent user-item interaction dataset.
